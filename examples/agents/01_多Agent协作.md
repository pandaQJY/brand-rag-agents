# 示例一：多 Agent 协作（完整链路）

这一例展示一句话如何被排成一条四环节流水线，并完整记录三样东西：
**被调用的 Agent 列表**、**每个 Agent 的中间结果**、**最终整合后的结果**。

## 输入

```
python -m apps.cli "请分析万悉科技官网目前哪些内容适合被 AI 引用，并给出 GEO 优化建议"
```

## 看点

| 环节 | 说明 |
|---|---|
| 路由 | 规则匹配命中两处词组，零模型调用、零延迟 |
| **依赖补齐** | 用户没提「客户会问什么」，但内容策略依赖它，系统自行补上「用户问题生成」并排定拓扑序 |
| 证据分级 | `[A档]` 判据来自万悉自己的品宣稿，`[B档]` 来自纯代码扫描，`[C档]` 为行业推测 |
| 整合收口 | 问题里的「并」字后面藏着第二问，收口环节把它拆成两节分别作答 |
| 溯源 | 每段答案都标注 `↑ 原样取自：<环节名>`，正文由代码原样搬运，非模型复述 |

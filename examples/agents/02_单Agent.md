# 示例二：单 Agent（无需协作）

不是所有问题都要跑满整条链路。这一例说明路由确实在**做减法**——
问「这家公司是做什么的」只需要官网信息分析一个环节，不该为了周全把四个都跑一遍。

## 输入

```
python -m apps.cli "万悉科技是一家什么公司？介绍一下"
```

## 看点

| 环节 | 说明 |
|---|---|
| 路由 | 只选中一个 Agent，耗时 31.1s（对比示例一的 104.4s） |
| **收口仍然要跑** | 官网信息分析固定输出 8 个小节，而用户只问「是什么公司」——收口环节挑出相关的几节，而不是把 8 节整份倒给用户 |
| 拆问 | 「是一家什么公司？介绍一下」被拆成两问，分别认领小节 |

  ✓ 整合结果　4.0s
